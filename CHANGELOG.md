## [1.1.0] - 2026-11-03

### Added

- **Birdy 2BLE** (`firmware/birdy-2ble`): серво (плавный `easeInOut`-ход),
  пьезо (6 семейств трелей с нарастанием/угасанием), контроль АКБ на P0.31,
  GATT-сервис управления `0xFFF0` (текстовые и бинарные команды), настройки в NVS,
  два одновременных BLE-подключения
- **Android-приложение** (`android/birdy-app`): Kotlin + Compose, автосканирование,
  приоритет `CO2-Birdy`, стрелочный индикатор положения серво, полоса CO₂ с порогом,
  индикатор АКБ, ползунки порога/гистерезиса/углов/времени хода/смещения температуры
- `firmware/birdy-2ble/docs/CONTROL-2BLE.md` — полный BLE-протокол

### Changed

- Структура репозитория: `firmware/base` (базовая прошивка), `firmware/birdy-2ble`, `android/birdy-app`
- README переписан под три части проекта
- CI собирает обе прошивки (`pio run -d firmware/base`, `-d firmware/birdy-2ble`)

### Fixed

- **I²C**: убран `Wire.end()` посреди работы — из-за него SCD41 уходил в клинч и
  переставал отдавать данные. Добавлены восстановление шины (9 тактов SCL + STOP),
  re-init датчика и эскалация до заводского сброса после повторных неудач
- **Зависание трели**: пьезо «тикает» и во время ожидания замера, запуск трели только
  из основного потока (была гонка с BLE-колбэком)
- **Ложные данные**: при неудачном замере в BTHome больше не уходят 400 ppm / 0.0 °C / 0.0 %
- **Калибровка CO₂ убрана** из прошивки и приложения (заводская калибровка + AFC),
  вместо неё — смещение температуры (`toff`)

## [0.2.0] - 2026-10-29

### Fixed

- **fix**: убран лишний второй `readMeasurement()` после цикла ожидания —
  корневая причина статичных «400 ppm / 0.0 °C / 0.0 %» в Home Assistant.
  В low-power-режиме SCD4x буфер результата опустошается при чтении,
  повторный `readMeasurement()` возвращал `false` (до следующего результата
  ~1.5 с) и реальные значения отбрасывались в пользу значений по умолчанию

### Added

- feat: первый замер выполняется сразу после boot (быстрое подтверждение данных)
- feat: лог-строка `RAW sensor: co2=.. temp=.. rh=..` — реальные значения из библиотеки
- feat: sanity-check диапазона (100–5000 ppm, −40…60 °C, 0…100 %):
  заведомо мусорные значения отбрасываются, сохраняется последний валидный замер
