# Birdy — Android-пульт для CO2-Birdy

Простое приложение для настройки «птички» по BLE: ползунки порогов и углов,
живой предпросмотр положения серво, батарея, тесты.

**Стек:** Kotlin · Jetpack Compose · Material3 · нативный Android BLE (без сторонних BLE-библиотек).

## Установка (готовый APK)

```
Birdy.apk   (в рабочей папке, рядом с папкой проекта)
```

1. Перекинь `Birdy.apk` на телефон (USB / Telegram / облако).
2. Открой файл → разреши «Установка из неизвестных источников» для файлового менеджера.
3. Запусти **Birdy**, разреши доступ к устройствам рядом (Bluetooth).

## Как пользоваться

**1. Поиск.** Приложение сразу начинает сканировать. Когда в эфире появляется
`CO2-Birdy`, он показывается крупной карточкой — нажми **ПОДКЛЮЧИТЬСЯ**.
Плата рекламируется окнами ~30 с раз в минуту, поэтому иногда нужно подождать
до минуты (в это время она экономит заряд). Список остальных устройств — ниже.

**2. Настройка.**

- **Стрелочный индикатор** — текущее положение серво. Зелёная метка = угол
  «жива», красная = «мёртва», стрелка = где птичка сейчас.
- **Полоска CO₂** — уровень газа, белая черта = текущий порог.
- **Ползунки:**
  - `Порог CO₂` — при каком значении птичка «умирает» (300…3000 ppm);
  - `Гистерезис` — насколько ниже порога нужно опуститься, чтобы ожить;
  - `Угол ЖИВА` / `Угол МЁРТВА` — положения серво (−100…100 %);
  - `Время хода` — плавность (0…30 с);
  - `Звук` — трель включена/выключена.
- **Предпросмотр:** пока тянешь ползунок угла, птичка **сразу двигается**
  (команда `goto=`), на отпускании — сохраняется (`alive=` / `dead=`).
- **Кнопки:** Замер · Свип · Трель ↑/↓ · Калибровка 400 · Сброс · Обновить.

Всё, что меняется, сразу пишется в NVS платы — переживает перезагрузку.

## Сборка из исходников

**Android Studio:** File → Open → папка `birdy-android` → Sync → Run.

**Командная строка** (Gradle 8.3+, JDK 17, Android SDK 34):

```bash
cd birdy-android
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Версии: AGP 8.1.0, Kotlin 1.9.10, Compose BOM 2023.10.01, minSdk 26, targetSdk 34.

> ⚠️ Проект лежит в папке с кириллицей в пути — в `gradle.properties` стоит
> `android.overridePathCheck=true`. Надёжнее собирать из ASCII-пути
> (например `C:\dev\birdy-android`).

## Протокол (прошивка 2BLE)

| UUID | Назначение |
|---|---|
| `FFF0` | сервис Birdy Control |
| `FFF1` | запись команд (бинарь **или** текст) |
| `FFF2` | notify: бинарный статус (6 байт) |
| `FFF3` | read: конфиг (14 байт) |
| `FFF4` | запись текстовых команд |
| `FFF5` | notify: текстовый ответ |

Приложение пишет **текстом** (`thr=`, `hyst=`, `alive=`, `dead=`, `sec=`, `snd=`,
`goto=`, `meas`, `sweep`, `up`, `down`, `cal=400`, `reset`, `get`).

`FFF3` (14 байт): `ver, thr(2), alive, dead, sec, snd, deadflag, co2(2), hyst(2), vbat_mv(2)`.

## Ограничения

- Пока телефон подключён, BTHome-реклама для Home Assistant приостанавливается;
  после «Выйти» — возобновляется.
- Одновременно можно держать до 2 подключений (телефон + планшет).
- Калибровку (`cal=400`) делать только в чистом воздухе — на улице или в
  проветренном помещении.
- APK собран в debug-варианте (подписан debug-ключом) — для личного использования.
