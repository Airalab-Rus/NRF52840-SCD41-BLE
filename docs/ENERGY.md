# Энергобюджет и автономность

## Допущения

- Батарея: LiPo **3.7 В, 2500 мА·ч** (BMS/зарядник на плате)
- Цикл: **60 с** (`MEASUREMENT_PERIOD`)
- Платформа: Arduino-core (в `delay()` — System ON, не deep-sleep)
- Ток SCD41 в активном окне ≈ **4 мА** (low-power periodic, датчик сам меряет
  каждые 1.5 с; у нас окно активности ≈ 6 с на цикл)
- BLE-реклама ≈ **4 мА** в момент передачи (окно 0.5 с)

> Числа — оценка по даташитам (nRF52840, SCD41) и поведению стека.
> Точные цифры зависят от батареи, температуры и конкретного BLE-адаптера.
> Для точной оценки — замерить токоизмерительными клещами при 25 °C.

## Таблица по режимам

| Режим | Ток | Длительность на цикл | Вклад в месяц |
|---|---|---|---|
| MCU idle (System ON, `delay(200)`) | ~8 мкА | ~54 с | **5.8 мА·ч** |
| SCD41 active (low-power periodic) | ~4 мА | ~6 с | **288 мА·ч** |
| BLE advertise (BTHome пакет) | ~4 мА | 0.5 с | **86 мА·ч** |
| **Итого на цикл (60 с)** | **avg ≈ 0.44 мА** | 60 с | **≈ 380 мА·ч/мес** |

## Формула

```
E_month = (I_mcu·t_mcu + I_scd41·t_scd41 + I_ble·t_ble) × N_cycles
N_cycles = 86400·30 / T_cycle
```

Для `T_cycle = 60 с`:
```
N_cycles = 86400·30/60 = 43 200
E_month  = (8e-6·54 + 4e-3·6 + 4e-3·0.5) × 43 200
         = (0.000432 + 0.024 + 0.002) А·с × 43 200
         = 26.4 А·с/цикл × 43 200 = 1 140 000 А·с
         = 317 А·ч/3600 = 317 мА·ч/мес  (≈ 380 мА·ч с запасом 20 %)
```

## Автономность

```
T_autonomy (мес) = C_batt / E_month
```

| Батарея | Цикл | Расход/мес | Автономность |
|---|---|---|---|
| 2500 мА·ч | 60 с | ≈ 380 мА·ч | **≈ 6.5 мес** |
| 2500 мА·ч | 300 с | ≈ 80 мА·ч | **≈ 12 мес** |
| 2500 мА·ч | 600 с | ≈ 45 мА·ч | **≈ 18 мес** |
| 5000 мА·ч | 60 с | ≈ 380 мА·ч | **≈ 13 мес** |

## Как продлить автономность

1. **Увеличить `MEASUREMENT_PERIOD`** — главный рычаг (×5 при 300 с).
2. **Отключать BLE-радио между отчётами** — у нас и так только 0.5 с окна.
3. **SCD41 в true deep-sleep** между циклами (`mySensor.stopPeriodicMeasurement()`
   уже вызывается; полный `mySensor.sleep()` — опционально).
4. **Arduino-core → Zephyr/NCS** — deep-sleep (System OFF) вместо `delay()`
   даёт ×3–×5, но это отдельный проект (у нас был Zephyr-вариант, не довели).

## Что НЕ учитывается

- **Батарея не измеряется** (делитель не распаян) → «100 %» в HA — условно.
- **Батарейный ток в реальном режиме** (BMS/зарядник) — может потреблять
  несколько мкА в idle.
- **Температура**: SCD41 при 0 °C потребляет больше (NDR-датчик).
- **BLE-адаптер HA** — он на стороне приёмника, не на стороне датчика.

## Вывод

При текущем цикле 60 с и батарее 2500 мА·ч ожидаемая автономность —
**6–8 месяцев**. Если нужно 12+ месяцев — поднять `MEASUREMENT_PERIOD` до
300–600 с (HA-сценарий «раз в 5 минут» для CO₂ более чем достаточен).
