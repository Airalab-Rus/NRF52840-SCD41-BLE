# Home Assistant

## Как HA видит устройство

Транспорт — **пассивный BLE (BTHome v2)**. HA не подключается к датчику
(не GATT-клиент), а просто слушает advertise-пакеты — датчик ничего
не ждёт и не отвечает, расход энергии минимальный.

- HA Core / Container ≥ **2023.x** (интеграция Bluetooth/BTHome)
- BLE-адаптер: на Raspberry Pi — USB-BT (BlueZ ≥ 5.66, `dmesg | grep Bluetooth`)
- Никакого MQTT, хаба, паролей — датчик анонимен, привязка идёт по BLE-адресу

## Настройка (5 шагов)

1. Плата запитана и уже шлёт пакеты (прошивка, см. [FLASHING.md](FLASHING.md)).
2. HA → **Настройки → Устройства и службы → + → Bluetooth**.
3. В списке появится устройство `CO2-AirNode` (или по MAC). → **Подключить**.
4. HA сам создаст сенсоры:
   - `sensor.<name>_temperature` (°C, точность 0.01)
   - `sensor.<name>_humidity` (%, точность 0.01)
   - `sensor.<name>_carbon_dioxide` (ppm)
   - `sensor.<name>_battery` (%)
   - диагностика: RSSI, сигнал
5. Готово. Значения обновляются при каждом принятом пакете (цикл 60 с).

## Что именно шлём в пакете (BTHome-IDs)

| ID | Поле | Единицы | Примечание |
|---|---|---|---|
| `0x00` | packet counter | — | инкремент на каждый пакет |
| `0x02` | temperature precise | 0.01 °C | SCD41 |
| `0x03` | humidity precise | 0.01 % | SCD41 |
| `0x12` | CO₂ | ppm | SCD41 (NDIR) |
| `0x01` | battery | % | **условно 100** — делитель АКБ не распаян |
| `0x15` | state: battery low | 0/1 | всегда 0 |

Пакет: 31 байт, **без шифрования** (BTHome encryption у нас выключен —
`bthome.begin(name, false, "", false)`).

## Если нужен push / MQTT

BTHome — уже push: HA получает пакет сам. MQTT-бэкенд **не нужен**.
Если нужен удалённый доступ к данным — это задача HA (Mosquitto + remote),
не датчика.

## Если устройство не находится

- Убедитесь, что BLE-адаптер включён: `hciconfig` / `bluetoothctl devices`
- Плата в радиусе (10 м внутри — ок, через 3 стены — может не ловить)
- В логе платы должно быть `[boot] BLE begin done` и `[meas] …`
- HA: Настройки → Bluetooth → удалить устройство и найти заново
- Полный чек-лист — [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## Удаление устройства из HA

Настройки → Устройства и службы → `CO2-AirNode` → **Удалить**.
Плата продолжает работать, просто HA его больше не слушает.

## Известные ограничения

- **Батарея 100 %** — статичное значение, реальная ёмкость не измеряется
  (делитель не распаян). См. [Known limitations](TROUBLESHOOTING.md#known-limitations).
- **OTA нет** — для обновления прошивки нужен USB (см. FLASHING.md).
- **Калибровка CO₂** — пока только в коде (`setUserReferenceCO2`),
  через BLE-команду не поддерживается.
