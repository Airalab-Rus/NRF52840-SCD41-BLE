# Troubleshooting

## Таблица симптомов

| Симптом | Вероятная причина | Решение |
|---|---|---|
| В HA статично **400 ppm / 0.0 °C / 0.0 %** | прошивка v0.1.0 (баг двойного `readMeasurement()`) | перепрошить v1.0.0 — см. [FLASHING.md](FLASHING.md) |
| В логе `SCD41 begin: FAILED` | I²C-проблема: пины, VCC/GND, перепайка | проверить SDA=P0.17, SCL=P0.20, 3.3 В, GND; опционально внешние pull-up 4.7 кОм |
| В логе `startLowPower: FAIL(stuck/bus)` | I²C-шина «зависла» (прежний мастер удерживал SCL) | полный power-cycle платы; I²C-bus-recovery (9 SCL-клоков) не реализован — см. limitations |
| В логе `read: FAIL (readyIn=120000ms)` | датчик не отвечает / плохой контакт | проверить питание SCD41, перепаять |
| `values out of range -> discarded` | датчик мёртв / шум на шине | проверить VCC/GND, pull-up |
| В HA **нет устройства** | BLE-адаптер выключен / дальность | `bluetoothctl devices` на HA-хосте; поднести плату ближе |
| В HA **нет сенсоров** (устройство есть) | HA не распознал BTHome-пакет | проверить, что прошивка v1.0.0+ (в логе `RAW sensor: …`); перезапустить HA |
| **Батарея всегда 100 %** | делитель напряжения не распаян | это ожидаемо (см. limitations) |
| **Диск `NICENANO` пропадает при копировании** | Windows отмонтирует диск при потере питания/сбое | копировать **сразу** после появления; файл ~260 КБ |
| `pio run` не находит платформу | нет `.platformio`-кэша / нет интернета | проверить сеть, или скопировать `~/.platformio` с рабочей машины |
| `pio run` — `arm-none-eabi-objdump: not found` | toolchain не установлен | `pio pkg install -g -p nordicnrf52 -t toolchain-gccarmnoneeabi` |
| `elf2uf2.py` — `first LMA != BASE` | ELF собран не под `nicenano` / неверный `board` | пересобрать `pio run -e nicenano` |
| HA-устройство «забылось» | HA перезапуск / BLE-адаптер перезагрузился | заново найти устройство в HA |
| Плата не заводится после прошивки | корявая прошивка / сломан бутлоадер | двойной RESET → перепрошить; в худшем случае — бутлоадер (см. FLASHING.md) |

## Known limitations

Что **осознанно не реализовано** в v1.0.0:

1. **Батарея = условное 100 %**. Делитель напряжения не распаян на плате,
   ADC не читается. Реальный уровень батареи в HA не отображается.
   **TODO:** распаять делитель, добавить `analogRead` + `ID_BATTERY`/`ID_VOLTAGE`.
2. **Нет OTA/DFU**. Обновление прошивки — только через USB (двойной RESET + UF2).
   **TODO:** BLE-DFU (SoftDevice S140 поддерживает) или ESP-NOW-канал.
3. **Нет калибровки CO₂ через BLE**. `setUserReferenceCO2` доступен в коде,
   но не через HA/команду. **TODO:** GATT-характеристика или BTHome-событие.
4. **Нет I²C-bus-recovery**. Если SCD41 завис (SCL зажат), плата не восстановит
   шину без power-cycle. **TODO:** 9-клоковый recovery в `doMeasure()`.
5. **Нет кнопки**. Никаких user-интерфейсов (короткое/длинное нажатие).
   **TODO:** GPIO + `attachInterrupt`.
6. **Нет deep-sleep**. Arduino-core держит System ON в `delay()`.
   Для ×3–×5 экономии — перенос на Zephyr/NCS (у нас был черновой вариант).
7. **Нет шифрования BTHome-пакетов**. `bthome.begin(..., encryption=false, ...)`.
   Для «параноидального» режима — включить + `bindKey` (HA поддерживает).
8. **Нет логов в файл**. Только UART-сериал. Для отладки на расстоянии —
   `pio device monitor` или BLE-лог (не реализовано).
9. **Нет теста на реальную ёмкость**. Расчёт в [ENERGY.md](ENERGY.md) — оценка.
   **TODO:** замерить токоизмерительными клещами при 25 °C.

## Диагностика по логу

Полный цикл в `pio device monitor`:

```
=== CO2-AirNode boot ===
[boot] BLE begin done
[boot] SCD41 begin: OK
[meas] startLowPower: OK
[meas] read: OK (readyIn=1450ms)
[meas] RAW sensor: co2=412 ppm temp=23.41C rh=41.28%
[meas] measure: OK co2=412 temp=23.4C rh=41.3%
```

Если какой-то строки нет — смотрите таблицу выше.

## Чек-лист приёмки (вручную)

- [ ] `pio run` — SUCCESS, Flash 135328 байт
- [ ] UF2 сгенерирован, `elf2uf2.py` валидирует
- [ ] Двойной RESET → диск → копирование → перезагрузка
- [ ] В логе: `SCD41 begin: OK`, `first measure: OK`, `RAW sensor: co2=…` (реальные числа)
- [ ] HA: устройство найдено, 4 сенсора с реальными значениями
- [ ] Значения меняются (дыхание/тепловая пушка) — не статичные
- [ ] Плата не греется > 40 °C через 1 ч работы
- [ ] После 24 ч работы в HA история непрерывна (нет провалов)
