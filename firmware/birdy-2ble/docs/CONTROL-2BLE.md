# 2BLE — управление «птичкой» по BLE

BTHome остаётся односторонним (HA только слушает рекламу). Для настройки
порогов и калибровки добавлен отдельный **GATT-сервис**, к которому
подключаются с телефона (**nRF Connect**). Реклама на время окна делается
`CONNECTABLE`, поэтому одновременно могут быть подключены **два устройства**
(`Bluefruit.begin(2, 0)`).

## Сервис

| UUID | Название | Тип | Размер | Описание |
|---|---|---|---|---|
| `0xFFF0` | Birdy Control | service | — | корневой сервис |
| `0xFFF1` | `cmd` | WRITE | 1–5 байт | команда |
| `0xFFF2` | `status` | NOTIFY | 6 байт | ответ на команду |
| `0xFFF3` | `info` | READ | 14 байт | конфигурация + напряжение АКБ (12-13) |
| `0xFFF4` | `tcmd` | WRITE | текст | **текстовые команды** (удобно с телефона) |
| `0xFFF5` | `tstat` | NOTIFY | текст | **текстовый ответ** |

## Текстовая настройка (самый простой путь с телефона)

nRF Connect -> сервис `FFF0` -> **SUBSCRIBE** на `FFF5` -> в `FFF4` выбрать
**Write -> Text (UTF-8)** и отправить, например:

```
thr=1200 alive=-20 dead=100 sec=8 hyst=80 snd=1
```

Ответ в `FFF5`:

```
ok thr=1200 hyst=80 alive=-20 dead=100 sec=8 snd=1 co2=1180 deadstate=0
```

| Ключ | Значение |
|---|---|
| `thr=` | порог «смерти», ppm (300…3000) |
| `hyst=` | гистерезис оживления, ppm (0…500) |
| `alive=` | угол «жива», −100…100 |
| `dead=` | угол «мёртва», −100…100 |
| `sec=` | время хода серво, с (0…30) |
| `snd=` | звук 0/1 |
| `cal` / `cal=400` | SPC-калибровка (по текущему / жёстко 400) |
| `meas` | немедленный замер + отправка в HA |
| `sweep` | плавный тест серво (3 хода + чирик) |
| `up` / `down` | тест трели |
| `reset` | сброс к дефолтам |
| `goto=<%>` | сразу поставить серво в положение (−100…100) — для подбора углов |
| `batcal=<%>` | поправка АКБ по мультиметру (50…200, сейчас 115) |
| `get` / `bat` | только прочитать значения / напряжение АКБ |
| `dfu` | перейти в DFU-бутлоадер (OTA по BLE) |

Можно отправлять по одному или несколько через пробел. Всё сохраняется в NVS.

## АКБ (делитель на P0.31)

Схема: `BAT+ -> R_top (15 кОм, маркировка 153) -> P0.31 (AIN7) -> R_bot (15 кОм, 153) -> GND`, коэффициент 2.0.

- В BTHome уходит: `voltage` (0.001 В), `battery` (%) и флаг `battery_low` при < 3.3 В.
- Процент — по кривой Li-Ion (4.2 В = 100 %, 3.3 В = 0 %).
- В текстовой консоли: `bat` или `get` — покажет `bat=4021mv`.
- Делитель высокоомный (1 МОм + 1.5 МОм) — SAADC может занижать.
  Для точности: конденсатор **100 нФ** с P0.31 на GND, а при необходимости —
  поправка `BIRDY_VBAT_CAL_PCT` в `platformio.ini` (истинное/показанное × 100).

### `status` (6 байт)

| Байт | Что |
|---|---|
| 0 | код: `0` OK, `1` неизвестная команда, `2` плохой аргумент, `3` CO2 слишком высокий для калибровки, `4` ошибка датчика |
| 1-2 | последнее измеренное CO2, ppm (LE) |
| 3 | флаги: bit0 — «мертва», bit1 — звук вкл, bit2 — датчик ОК |
| 4-5 | текущий порог, ppm (LE) |

### `info` (12 байт, read)

| Байт | Что |
|---|---|
| 0 | версия формата (`1`) |
| 1-2 | порог CO2, ppm (LE) |
| 3 | угол «жива» (-100..100) |
| 4 | угол «мёртва» (-100..100) |
| 5 | время хода серво, сек |
| 6 | звук (0/1) |
| 7 | «мертва» (0/1) |
| 8-9 | последнее CO2, ppm (LE) |
| 10-11 | гистерезис, ppm (LE) |

## Команды (`0xFFF1`)

| cmd | Аргументы | Действие |
|---|---|---|
| `0x01` | — | **SPC-калибровка по текущему значению**. Защита: если CO2 > `BIRDY_SPC_MAX_PPM` (600) -> код `3`, ничего не пишем. Делать в проветренном помещении/на улице. |
| `0x02` | — | SPC-калибровка **жёстко на 400 ppm** (без проверки — осознанно) |
| `0x03` | ppm lo, hi (LE) | установить порог «смерти» (300-3000 ppm) |
| `0x04` | int8 | угол «жива» (-100…100 %) |
| `0x05` | int8 | угол «мёртва» (-100…100 %) |
| `0x06` | 0…30 | время хода серво, сек |
| `0x07` | — | немедленный замер + отправка BTHome |
| `0x08` | — | сброс настроек к дефолтам |
| `0x09` | 0/1 | звук вкл/выкл |
| `0x0A` | — | тест: восходящая трель |
| `0x0B` | — | тест: нисходящая трель |
| `0x0C` | — | тест: свип серво из края в край |

Все параметры (порог, гистерезис, углы, темп, звук) сохраняются в NVS —
файл `/birdy.cfg` во внутреннем LittleFS (регион `0xED000`, бутлоадер не
затрагивается) и переживают перезагрузку.

## Как подключиться (nRF Connect, Android/iOS)

1. Устройство рекламируется **30 секунд** после каждого замера (раз в 60 с).
   Если окно закрылось — дождись следующего цикла или отправь `0x07`
   (принудительный замер снова откроет окно).
2. nRF Connect -> **SCAN** -> найди `CO2-Birdy` -> **CONNECT**.
3. Вкладка **Services** -> сервис с UUID `FFF0`.
4. Нажми **SUBSCRIBE** на `FFF2`, чтобы видеть ответы.
5. Прочитать конфиг: характеристика `FFF3` -> **Read**.

### Примеры байтов

| Что | Байты (hex) |
|---|---|
| Калибровка по текущему | `01` |
| Калибровка на 400 ppm | `02` |
| Порог 800 ppm | `03 20 03` |
| Порог 1200 ppm | `03 B0 04` |
| Угол «жива» = -100 % | `04 9C` (-100 как int8) |
| Угол «мёртва» = 100 % | `05 64` |
| Ход 5 с | `06 05` |
| Замер сейчас | `07` |
| Сброс | `08` |
| Звук выкл | `09 00` |
| Тест трели вверх | `0A` |
| Тест трели вниз | `0B` |
| Свип серво | `0C` |

## Ограничения

- Пока телефон подключён, BTHome-реклама приостанавливается (HA в этот момент
  не обновляется) — после отключения всё возвращается.
- Калибровка и свип **откладываются** в основной цикл (`loop()`), чтобы не
  трогать I2C из BLE-потока; результат придёт в `status`.
- SPC-калибровка пишется в сам датчик SCD41 и живёт там независимо от прошивки.
- `2BLE` — отладочная ветка: connectable-реклама и 30-секундное окно тратят
  больше энергии, чем чистый BTHome (для батарейного варианта окно можно
  уменьшить через `BIRDY_ADV_WINDOW_SEC`).

## OTA DFU по BLE (без двойного RESET)

В прошивке поднят сервис `BLEDfu` (Nordic legacy DFU), поэтому плату можно
перепрошивать по воздуху — кнопки не нужны.

### 1. Собрать DFU-пакет

`firmware.zip` от PlatformIO для BLE-DFU **не подходит** — нужен пакет
`adafruit-nrfutil`:

```bash
pip install adafruit-nrfutil
pio run -d firmware/birdy-2ble
adafruit-nrfutil dfu genpkg --dev-type 0x0052 \
  --application firmware/birdy-2ble/.pio/build/nicenano/firmware.hex \
  CO2-Birdy-2BLE-dfu.zip
```

### 2. Залить с телефона

1. Установить **Bluefruit Connect** (iOS/Android).
2. Подключиться к `CO2-Birdy`.
3. Меню **DFU** → выбрать `CO2-Birdy-2BLE-dfu.zip` → Upload.
   Приложение само переведёт плату в бутлоадер и вернёт в приложение.

### Альтернатива — вручную перевести в DFU

Отправить текстовую команду `dfu` (nRF Connect / BLE Controller) — плата
перезагрузится в бутлоадер и начнёт рекламироваться как `DfuTarg`.
Дальше — DFU из Bluefruit Connect уже к `DfuTarg`.

### Ограничения

- OTA работает, только пока приложение живо и реклама идёт (окна по 30 с).
- Если прошивка повисла намертво — только двойной RESET + UF2.
